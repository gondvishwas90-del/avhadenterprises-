# Design Philosophy

Every design must be:

* Premium
* Minimal
* Elegant
* Modern
* Purpose-driven
* Conversion-focused
* Accessible
* Responsive
* Scalable
* Performance optimized

Avoid unnecessary decoration.

Every visual element must solve a problem.

# Design Inspiration

Use inspiration from products and studios such as:

* Apple
* Stripe
* Linear
* Vercel
* Framer
* Notion
* Figma
* Airbnb
* Shopify
* Webflow

Reference award-winning work from:

* Awwwards
* CSS Design Awards
* FWA
* Behance
* Dribbble

Never copy designs directly.

Use inspiration only to create original work.

# Typography Standards

Prefer premium fonts such as:

* Inter
* Geist
* Plus Jakarta Sans
* Satoshi
* General Sans
* IBM Plex Sans
* Space Grotesk
* Manrope

Use:

* Clear hierarchy
* Comfortable line-height
* Consistent spacing
* Limited font weights

# Color Strategy

Create colors based on:

* Brand personality
* Contrast
* Accessibility
* Emotional psychology

Avoid random gradients.

Use restrained premium palettes.

# Spacing System

Use an 8px spacing system.

Maintain:

* Consistent margins
* Consistent padding
* Grid alignment
* Visual rhythm

Whitespace is part of the design.

# Component Standards

Every component should be:

* Reusable
* Responsive
* Accessible
* Modular
* Scalable

Examples:

* Buttons
* Cards
* Navigation
* Hero Sections
* Pricing Tables
* Testimonials
* FAQ
* Forms
* Footer
* Dashboard Widgets

# Motion Guidelines

Use motion only to improve UX.

Prefer:

* Smooth easing
* Micro interactions
* Scroll animations
* Hover feedback
* Page transitions

Never create distracting animations.

# Accessibility Standards

Always follow WCAG guidelines.

Ensure:

* Keyboard navigation
* Focus states
* Color contrast
* Semantic HTML
* Screen reader compatibility
* Touch-friendly targets

# Performance Standards

Optimize for:

* Core Web Vitals
* Lazy Loading
* Responsive Images
* Font Optimization
* Clean HTML
* Optimized CSS
* Efficient JavaScript

# Responsive Breakpoints

Design for:

* Mobile
* Tablet
* Laptop
* Desktop
* Large Desktop

Every layout should adapt gracefully.

# UX Principles

Always prioritize:

* Simplicity
* Clarity
* Discoverability
* Readability
* User confidence
* Fast task completion
* Reduced cognitive load

# Deliverables

Every completed design should include:

* Wireframe
* High-fidelity UI
* Responsive layouts
* Design system
* Components
* Color tokens
* Typography scale
* Spacing tokens
* Icon usage
* Interaction notes
* Developer handoff guidance

# Success Checklist

Before considering any design complete, verify:

* Premium visual quality
* Pixel-perfect alignment
* Responsive across devices
* Accessibility compliance
* Strong visual hierarchy
* Consistent spacing
* Brand consistency
* Fast-loading assets
* Conversion-focused layout
* Original design
* Production-ready quality

Reject any design that does not meet these standards.
